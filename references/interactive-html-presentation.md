# 交互式 HTML 演示页

当 HTML 工程也作为演讲/录屏时打开的交互式演示页时，默认提供轻量图片摆放能力，不增加显式“编辑模式”：

- 在当前幻灯片按 `Ctrl+V` / `⌘V` 粘贴剪贴板图片；同时接受剪贴板图片文件与复制的 HTML 图片。将图片放在鼠标位置附近；鼠标不在幻灯片上时放在当前页中央。
- 每一页都支持拖入本地图片。插入后可在整张幻灯片范围内自由拖动、等比缩放和删除，不把图片限制在原有占位框中。
- 默认不显示左上角“稿/讲稿”按钮，也不把讲稿面板作为演示操作入口。讲稿内容仍可作为内部备注数据保留。
- 图片内容和几何位置必须持久化，关闭后重新打开同一演示文件时自动还原。用 IndexedDB 保存图片 Blob 与布局；小型实现可用 localStorage 保存 data URL。不要只保存临时 `blob:` URL、内存对象或页面 DOM 状态。
- 给每份演示分配稳定的存储键，按幻灯片 ID 保存图片内容、位置、尺寸及必要的替代文本。图片写入完成后再显示成功提示；存储失败时说明图片没有保存，不能静默降级成仅本次会话有效。
- 图片只保存在本机浏览器存储，不上传。持久化范围需明确为同一浏览器配置和同一演示地址；清理浏览器站点数据、换浏览器或换设备后不承诺自动迁移。若要求跨设备或随文件分发，应另提供显式导出/嵌入功能。
- 验收时插入并移动一张图片，关闭页面后用同一浏览器重新打开同一文件，确认图片、大小和位置都恢复；再切换幻灯片确认各页互不串图。对 `file://` 地址需在目标浏览器实际验收其存储行为。

本规则只适用于交互式演示页；纯视频最终渲染不承载浏览器编辑器控件。
