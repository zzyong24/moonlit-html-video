# 月明视觉系统

## 画布与品牌

- 逻辑画布：1080×1920；4K 输出用整数 DPR 或高质量母版升级，不把 HTML 逻辑坐标直接写成 2160×3840。
- 色彩：深炭黑 `#080A0B`、暖白 `#F3F0E8`、科技绿 `#39EC88`；警示色只用于问题或噪声。
- 标题、主舞台和字幕分区；字幕位于底部安全区，不能与主舞台争夺层级。

## 顶部章节进度

v11 默认安全框：`x=54, y=88, width=972, height=92`（1080×1920 逻辑画布）。这是用户认可的项目默认值，不是抖音官方永久像素规范。

- 章节数跟随论证结构，常见为 4–6 段。
- 每段填充时长必须等于真实章节时长；完成段保持填满，当前段连续增长。
- 章节切换只做小范围脉冲，不让进度组件遮住标题、品牌或平台 UI。

## 转场与声音

- 默认：上一幕 `0.22s` 降亮淡出 → 暗色呼吸帧 → 下一幕 `0.30s` 柔和显现。
- 前后两幕正文不能同时可见；持久顶部进度负责维持连续感。
- 每次场景交接可使用 `assets/transition-click.wav`，默认 `data-volume=0.08`，音频起点比视觉交接提前约 `0.04s`。
- 不用全屏绿/白盖层，不用窄线扫过整屏，不默认使用 whoosh、glitch 或 impact。

## 素材选择

| 语义 | 主视觉 |
|---|---|
| 产品功能、界面、结果 | 真实截图/录屏，`contain` |
| 记忆、边界、再次召回等抽象概念 | 月明宇航员 AI 场景图 |
| 计数、筛选、堆积、交接 | HTML/GSAP 专属状态变化 |
| 结论 | 大字与单一证据，不堆装饰 |

AI 场景图使用 3:2 横图以适配主舞台，推荐 1536×1024。Prompt 必须重复身份约束：白色圆润人形宇航服、黑色玻璃面罩、绿色发光耳环和状态灯、完整人类比例、单人、无文字；负面约束包括虫、蠕虫、长躯干、额外肢体、机器人脸和霓虹堆叠。
