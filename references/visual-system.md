# 月明视觉系统

## 画布与品牌

- 逻辑画布：默认 16:9 横版 1920×1080（`--aspect 16:9`）；用户指定竖版时 1080×1920。4K 输出用整数 DPR 或高质量母版升级，不把 HTML 逻辑坐标直接写成 3840×2160 / 2160×3840。
- 色彩、字体、字号与缓动：只取 `moonlit-content-engine/references/brand-tokens.md` 的深色 `night` 主题（深蓝夜 `#0E1A28`、暖白 `#F3F0E8`、亮铜橙 `#E0894F`）；语义色只在内容有对应含义时用。旧“深炭黑 + 科技绿”仅用于维护历史工程。
- 动效语法（词级揭示、真人/元素变形、B-roll 类型库、密度检查）以 `moonlit-talking-head-video/references/motion-grammar.md` 为唯一来源；本文件只写 HTML 模式的特例。
- 标题、主舞台和字幕分区；字幕位于底部安全区，不能与主舞台争夺层级。

## 顶部章节进度

默认安全框：16:9 为 `x=64, y=40, width=1792, height=64`（1920×1080）；竖版沿用 v11 `x=54, y=88, width=972, height=92`（1080×1920）。这是项目默认值，不是平台官方永久像素规范。

- 章节数跟随论证结构，常见为 4–6 段。
- 每段填充时长必须等于真实章节时长；完成段保持填满，当前段连续增长。
- 章节切换只做小范围脉冲，不让进度组件遮住标题、品牌或平台 UI。

## 转场与声音

- **同一章内不翻页**：beat 之间在同一舞台上变形——上一拍的主视觉缩小、移位或压暗留作上下文，新元素从它身上长出来（例：打字框打完缩到左上角当标题，结果卡从下方长出）。不使用淡出淡入，不让旧元素无理由消失。
- **换章才整体过渡**：上一幕 `0.22s` 降亮淡出 → `0.30s` 新章显现，配章节条脉冲；这是唯一允许前后两幕不同屏的地方。
- 音效按品牌令牌三档：入场/落位用 `assets/transition-click.wav`（默认 `data-volume=0.08`，提前约 `0.04s`）；舞台平移可用 soft whoosh；impact 只给满屏大字，每 30–60 秒最多 1 次。
- 不用全屏绿/白盖层、窄线扫屏、glitch。

## 素材选择

| 语义 | 主视觉 |
|---|---|
| 产品功能、界面、结果 | 真实截图/录屏，`contain` |
| 记忆、边界、再次召回等抽象概念 | 本期母意象（`creative_concept`）的 HTML 状态变化；确需情境画面时用语义匹配的 AI 场景图，用户本期指定时才用月明宇航员 |
| 计数、筛选、堆积、交接 | HTML/GSAP 专属状态变化 |
| 结论 | 大字与单一证据，不堆装饰 |

AI 场景图使用 3:2 横图以适配主舞台，推荐 1536×1024。使用月明宇航员时，Prompt 必须重复身份约束：白色圆润人形宇航服、黑色玻璃面罩、绿色发光耳环和状态灯、完整人类比例、单人、无文字；负面约束包括虫、蠕虫、长躯干、额外肢体、机器人脸和霓虹堆叠。
